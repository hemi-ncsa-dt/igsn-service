# Pinned dependency closure for reproducible images.
#
# pyproject.toml declares *what* this service needs; this file pins *which
# versions* get installed, so two builds of the same commit produce the same
# tree. Without it `pip install` re-resolves at build time and an image built
# today differs from one built last week for no recorded reason.
#
# Regenerate after changing dependencies in pyproject.toml:
#
#     python -m venv /tmp/pin && /tmp/pin/bin/pip install '.[backfill]'
#     /tmp/pin/bin/pip freeze | grep -v '^igsn-service' | sort -f
#
# Covers the base dependencies plus the `backfill` extra (girder-client), which
# is what the image installs. Dev/test tools are deliberately not pinned here.
